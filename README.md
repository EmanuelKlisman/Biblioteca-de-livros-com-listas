Olá, pessoal! 👋

Seguindo no compartilhamento da minha evolução no mundo da programação, nos últimos dias desenvolvi um pequeno projeto/exercício em Python para praticar alguns conceitos fundamentais.

Nesse projeto trabalhei principalmente com:

* **Listas**
* **Estruturas de repetição** (`while` e `while True`)
* **Estruturas de decisão** (`if`, `elif`, `else`)

A ideia foi criar uma **biblioteca virtual no terminal**, permitindo interações com o usuário para:

* adicionar livros às estantes
* visualizar a quantidade de livros cadastrados
* navegar entre diferentes menus do sistema

Reconheço que o código ainda pode ser otimizado e ter menos linhas, mas o objetivo principal do exercício foi **praticar lógica de programação**, especialmente o uso de estruturas de repetição e controle de fluxo.

🚀 Seguimos evoluindo um pouco todos os dias!
